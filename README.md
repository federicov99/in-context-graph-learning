# In-context graph learning in language models: induction circuits, learning curves and scaling laws

Federico Viola · November 2026 · **[Write-up (PDF)](paper/ICL_writeup.pdf)**

When a language model reads a random walk over a graph whose nodes are unrelated single-token words, it learns in
context to predict valid next words, and its hidden states come to mirror the graph
([Park et al., 2025](https://arxiv.org/abs/2501.00070)). This repository contains the notebooks, results and write-up
of two experiments in this setting:

1. **Head ablations.** Following [Arditi (2026)](https://iclr-blogposts.github.io/2026/blog/2026/iclr-induction/), we
   ablate the top induction and previous-token heads, and separate their effect at the final token from their effect
   in the preceding history. On Llama-3.1-8B, previous-token heads matter only in the history, while induction heads
   matter in both places.
2. **Learning curves.** We fit the accuracy curve with the belief model of
   [Kowalyshyn et al. (2026)](https://arxiv.org/abs/2605.08405) and with Park et al.'s two-line description, check
   that single walks have the same S-shape, and scan graph sizes: the midpoint of the rise grows roughly as
   N\* ≈ 4.75 n^0.89 in the number of vertices n.

## Results used in the write-up

All runs use Llama-3.1-8B on the 4×4 grid unless stated otherwise. Each run folder contains the files written by the
notebook, including a `README.txt` that describes every file and the run's settings (`experiment.json` for the first
notebook, `summary.json` for the second).

| Folder | Settings | In the write-up |
|---|---|---|
| `results/experiment1/main_16walks/` | Park et al.'s words; 16 walks of 1,400 words; k = 1, 2, 4, 8, 16, 32; random controls (4 draws) | Figures 1–4 |
| `results/experiment1/k32_layer_matched/` | Same walks; k = 32 only; layer-matched controls (4 draws) | Table 1, Figure 5 |
| `results/experiment1/seed42/`, `seed44/`, `seed46/` | Words drawn at random (seeds 42, 44, 46); 16 walks of 1,400 words; k = 32 only | Figure 6 |
| `results/experiment2/square4_park_words/` | Park et al.'s words; 32 walks of 4,000 tokens | Figures 7–8, fit comparison and single-walk check |
| `results/experiment2/size_scan_square/` | Square grids from 3×3 to 12×12; word seeds 0–4; 32 walks per run | Figures 9–10 |

The runs with k = 32 only were made with `HEAD_COUNTS = "32"`, which is much faster. For the identified heads they
use the same walks and heads as the main run, and give the same drops.

## Preliminary runs

`results/experiment1/preliminary/` and `results/experiment2/preliminary/` hold earlier runs with other models, graphs
and settings, mostly with 4 walks. They are exploratory, and the numbers in the write-up do not rest on them. Some were
made with earlier versions of the notebooks, which differ in the controls and the figures; each run records its
settings. Runs of the second notebook on triangular or hexagonal graphs made before 22 November 2026 used an earlier
construction of those graphs.
